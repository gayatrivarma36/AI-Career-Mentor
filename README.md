# AI Career Mentor

AI Career Mentor is a modern career guidance web app that helps users explore career paths, analyze skill gaps, generate interview questions, improve resumes, and discover learning resources.

## Project Overview

This project combines:
- Frontend: HTML, CSS, and JavaScript
- Backend: Python with Flask
- AI assistance: Gemini-style fallback guidance for career support features

## Features

- Career roadmap generator
- Skill gap analysis
- Interview question generator
- Resume improvement suggestions
- Course recommendations
- Dashboard and resume analyzer pages

## Project Structure

- dashboard.html - Main dashboard interface
- resume-analyzer.html - Resume analysis page
- css/ - Styling files
- js/ - Frontend JavaScript
- backend/ - Flask backend and API routes

## How to Run

1. Open the backend folder
2. Activate the virtual environment
3. Run the Flask server:

```powershell
cd backend
.\venv\Scripts\Activate.ps1
python main.py
```

4. Open the app in your browser:
   - http://127.0.0.1:5000/
